The full ExactHousing homepage with a lightweight real-time 3D room material study and the original scroll-driven five-chapter home-making story.

== Installation ==
1. Upload the plugin ZIP through Plugins > Add New > Upload Plugin.
2. Activate ExactHousing Integrated 3D Homepage.
3. Create a full-width page in WordPress/Elementor and add [exacthousing_homepage] using a Shortcode widget.
4. Use a blank/canvas page template to avoid duplicating your theme header and footer.

== Notes ==
The included room model is conceptual. Three.js loads from jsDelivr and requires an internet connection.
