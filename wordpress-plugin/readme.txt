Homepage content for ExactHousing with a real-time 3D material study and scroll-driven five-chapter home-making story. The plugin template intentionally does not include its own site header or footer, so your WordPress theme or Elementor global header/footer can appear.

== Installation ==
1. Upload the plugin ZIP through Plugins > Add New > Upload Plugin.
2. Deactivate and replace the previous ExactHousing Integrated 3D Homepage plugin version, then activate this version.
3. Create/edit the Home page and add [exacthousing_homepage] using an Elementor Shortcode widget.
4. Set the page layout to Elementor Full Width or your theme's Default layout. Do not use Elementor Canvas, because Canvas suppresses the global header and footer.

== Notes ==
The included room model is conceptual. Three.js loads from jsDelivr and requires an internet connection. Header and footer content come from your active WordPress theme or Elementor Theme Builder.
