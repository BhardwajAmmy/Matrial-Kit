EXACTHOUSING — REAL 3D ROOM CUSTOMIZER INTEGRATION

This is a complete replacement package for the original full homepage source, using the newer procedural 3D room as the hero.

WHAT THIS VERSION DOES
- Replaces the old image-based material hero with a real Three.js room model.
- Puts rotate/zoom interactions on the model and gives the room a complete side wall with a window.
- Removes the large curated-palette column. The material controls are a short, low-profile strip below the room, with small swatches and reset.
- Changes actual separate mesh materials for cabinetry, walls, floor and countertops.
- Preserves the original five-chapter scroll-driven Three.js particle story, including the dots forming a plan/house.
- Preserves the supplied original project, statement, services, pricing, contact and footer sections.

HOSTINGER
Upload the contents of the standalone ZIP into your preview folder, replacing index.html and the assets/story.css and assets/story.js files. The ZIP also adds assets/material-room.js. No image assets are required for the new 3D hero. Keep all files in their provided relative folders.

WORDPRESS
Install the provided plugin ZIP and place [exacthousing_homepage] in an Elementor Shortcode widget on a full-width/blank page. The plugin contains the complete homepage markup and its local CSS/JS assets.

NOTE
The room is a purpose-built conceptual model, not a construction model or the uploaded 3ds Max scene. Three.js loads from jsDelivr, so the page needs an internet connection.
